# 반딧불이 잡기 게임 (Catch the Firefly)

어두운 숲속에서 무작위로 나타났다 사라지는 반딧불이를 제한 시간 안에 클릭(터치)해서 잡는 웹 미니게임입니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 별도 설치나 빌드가 필요 없습니다.

## PRD

### 1. 개요 및 목적

- **프로젝트명:** 반딧불이 잡기 게임 (Catch the Firefly)
- **목적:** 어두운 숲속 배경에서 무작위로 나타났다 사라지는 반딧불이를 제한 시간 내에 마우스나 터치로 클릭하여 점수를 얻는 경량 캐주얼 웹 게임
- **타겟 사용자:** 간단하게 브라우저에서 조작하며 즐길 수 있는 미니게임을 선호하는 일반 사용자

### 2. 화면 구성 요소

- **상단 헤더:** 게임 타이틀 "반딧불이 잡기", 점수판(`점수: 0점`), 남은 시간(`남은 시간: 30초`)
- **중앙 게임 플레이 영역:** 어두운 밤숲 배경(#1a2b3c), 반딧불이가 무작위로 등장하고 이동하는 `<canvas>` 플레이 판
- **제어 버튼:** 게임을 시작하는 시작 버튼
- **게임 종료 오버레이:** 최종 점수 안내, 다시하기 버튼(초기화면으로 돌아가 재시작)

### 3. 게임 상태

| 변수 | 설명 |
| --- | --- |
| `gameState` | `READY`(대기 중), `PLAYING`(진행 중), `GAMEOVER`(종료) |
| `score` | 반딧불이를 잡을 때마다 1점씩 증가 |
| `timeLeft` | 게임 시작 시 30초, 1초씩 감소 |
| `fireflies` | 화면에 떠 있는 반딧불이의 위치(x, y), 크기, 깜빡임 상태 등 |

### 4. 게임 규칙

- **시작:** '시작하기' 버튼을 누르면 `score`는 0, `timeLeft`는 30으로 초기화되고 `PLAYING` 상태가 됩니다.
- **종료:** `timeLeft`가 0이 되면 `GAMEOVER` 상태가 되고 최종 점수 오버레이가 나타납니다.
- **등장:** 반딧불이는 무작위 위치에 나타나 1.8~3.2초 동안 깜빡이며 떠다니다가 사라집니다. 동시에 최대 7마리까지 떠 있고, 시간이 지날수록 더 자주 등장합니다.
- **잡기:** 반딧불이를 클릭하거나 터치하면 1점을 얻고 반딧불이는 사라집니다. 터치로도 잡기 쉽도록 판정 범위를 반딧불이보다 넉넉하게 잡았습니다.
- **다시하기:** 종료 화면의 '다시하기' 버튼을 누르면 초기화면(`READY`)으로 돌아갑니다.
